# Changelog

All notable changes to `lite-llm-security` are documented in this file.

## [0.1.0] - 2026-03-01
### Added
- Memory-safety auditing model for unsafe and FFI boundaries.
- Secure model loading with deterministic digest and signature verification.
- Encryption-at-rest and zeroization policy primitives.
- Tier authorization and role-based access controls.
- Deterministic tamper-evident audit log chain.
- Key management, sandbox capability controls, compliance artifacts, and hardening checklist.
- Security-focused tests for integrity, authz, audit, encryption, key, and sandbox controls.
